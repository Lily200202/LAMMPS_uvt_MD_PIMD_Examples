# Constant-Potential MD and PIMD Paper Validation

This orphan branch contains the compact validation package accompanying the manuscript
*A unified and validated constant-potential path-integral molecular dynamics framework*.
The files are intentionally separate from the LAMMPS implementation pull request so that
simulation models and processed data do not enlarge the source-code review history.

See [`validation/README.md`](validation/README.md) for the manuscript-to-data map,
reproduction commands, software provenance, and data-retention policy.
